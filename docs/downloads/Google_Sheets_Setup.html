온라인 가격 저장 설정

가족 공동 가격표를 관리하는 계정에서 한 번 설정하면, 가족이 같은 시트에 네이버·쿠팡 가격을 저장할 수 있습니다.

Apps Script 전체 코드 열기 시트 설정 ZIP 다운로드

  1. 위의 Apps Script 전체 코드 열기를 선택하고 코드 전체를 복사하세요. 첫 함수는 setupOnlineOffers()입니다.
  2. 가격을 보관하는 기존 구글 시트에서 확장 프로그램 → Apps Script → Code.gs를 엽니다. 편집기 안의 기존 코드 전체를 방금 복사한 내용으로 교체하고 저장하세요.
  3. 구글 시트 탭을 새로고침하고 가격표 관리 → 온라인 가격 저장 준비를 누르세요. 권한 요청이 뜨면 승인합니다. 온라인가격이력 탭이 생기면 준비가 끝난 것입니다. Apps Script 편집기의 함수 목록에서 setupOnlineOffers를 실행해도 됩니다.
  4. Apps Script에서 배포 → 배포 관리 → 기존 웹 앱의 수정(연필) → 새 버전 → 배포를 누르세요. 같은 배포를 업데이트하면 기존 사이트의 웹 앱 주소와 가족 비밀번호를 계속 쓸 수 있습니다.
  5. 한눈단가로 돌아가 새로고침하고 네이버·쿠팡 가격 저장을 누르세요. 상품 링크를 붙여넣고, 공동 기록 → 네이버·쿠팡 온라인 기록에서 저장한 항목을 확인하세요.
예전 설정 파일을 사용했고 권한 오류가 표시될 때

오류 메시지에 스프레드시트나 외부 요청 권한이 표시되고, 이전에 이 앱의 설정 ZIP에서 appsscript.json을 복사했다면 그 파일의 oauthScopes를 확인하세요. 이 가격표 전용 프로젝트에서 예전 두 권한(spreadsheets.currentonly, script.container.ui)으로 고정해 둔 경우, 해당 oauthScopes 항목을 제거하면 Apps Script가 현재 코드에 필요한 권한을 감지합니다. JSON을 저장한 뒤 3~4단계에서 권한을 다시 승인하세요.
