UNITCART · 한눈단가

구글 시트에서
장보기 가격을 비교하세요.

코스트코 기준 단가와 쿠팡·네이버에서 직접 확인한 가격을 같은 기준으로 계산합니다.

먼저 알아둘 점

시트만으로도 비교 수식과 검색 링크가 작동합니다. Apps Script 설치는 사이트 기록을 옮기거나 판매가 입력 도우미를 사용할 때만 필요합니다.

현재 버전은 반자동입니다. 검색 결과에서 실제 판매가·배송비·옵션을 확인해 입력하면 계산이 자동으로 이루어집니다. 실시간 가격 수집, 전체 온라인 최저가 보장, 로켓배송·공식몰 자동 인증은 제공하지 않습니다.

네이버는 쇼핑 검색 API를 2026년 7월 31일 종료했습니다. 이 도구에는 종료된 API 호출이나 쇼핑몰 크롤러가 들어 있지 않습니다. 네이버 공식 공지

1. 구글 시트로 열기

  1. 전달받은 .xlsx 파일을 본인 Google Drive에 업로드합니다.
  2. 파일을 Google 스프레드시트로 엽니다.
  3. 필요한 경우 파일 → Google 스프레드시트로 저장을 선택해 구글 시트 형식으로 변환합니다. 원본 XLSX의 Office 편집 상태에서는 Apps Script 메뉴가 보이지 않을 수 있습니다.
  4. 비교요약에서 데이터 구분을 실제로 바꿉니다. 예시 행은 가상의 설명용 가격입니다.
  5. 상품에 코스트코 가격을, 판매가에 확인한 온라인 가격을 입력합니다. 비교 결과는 비교요약에 표시됩니다.

구글 시트로 변환한 뒤 데이터 유효성 검사, 날짜, 수식 결과를 확인하세요. XLSX를 열기만 해도 기본 비교 기능을 사용할 수 있으며, Apps Script는 별도로 설치합니다.

2. 입력 규칙

한국 날짜 기준: 구글 시트의 파일 → 설정 → 시간대를 서울(GMT+09:00)로 맞추세요. 시트의 TODAY()와 도우미의 오늘 날짜가 같은 기준으로 계산됩니다.

항목입력 방법
총량묶음 전체의 개수·g·mL·m를 입력합니다. 예: 750mL × 3병은 2,250mL. 100mL 기준을 골라도 총량에는 2,250을 입력합니다.
코스트코 단가총 결제금액과 총량으로 계산하거나 직접입력 단가를 사용할 수 있습니다. 직접 단가는 선택한 비교 단위 기준입니다.
배송비무료배송을 실제로 확인했을 때만 0. 모르면 빈칸을 둡니다.
할인본인에게 실제 적용되는 할인만 입력하고 할인확인을 예로 선택합니다. 예상 적립금은 빼지 않습니다.
동일·유사같은 제품 라인·옵션이면 동일, 다른 브랜드·성분·재질·단계 등은 유사로 구분합니다. 수량이 다른 같은 제품은 같은 기준 단가로 비교할 수 있습니다.
검색어검색어의 앞뒤 공백을 제거하고, 비어 있으면 상품명으로 검색합니다. 네이버 검색어에 “공식”을 강제로 붙이지 않습니다. “공식”이라는 검색어는 공식몰 필터가 아닙니다.
네이버 공식몰판매처 이름에 “공식”이 있다는 이유만으로 확정하지 않습니다. 공식판매처 표시나 브랜드의 판매처 안내를 확인하고 근거 URL을 기록합니다.
로켓 우선쿠팡 로켓배송·로켓프레시를 먼저 비교하고 판매자로켓과 일반배송을 구분합니다. 최저 단가와 로켓 우선 추천은 다를 수 있습니다.
가격 확인일직접 확인한 날짜입니다. 오래된 가격·품절·미확인 조건은 추천에서 제외될 수 있습니다.

3. 선택 기능: Apps Script 설치

설치는 데스크톱 웹 구글 시트에서 진행하는 것이 편합니다. 모바일 구글 시트 앱에서는 사용자 메뉴·사이드바 사용이 제한될 수 있습니다. 휴대폰에서는 사이트나 기본 시트 입력을 사용하세요.

  1. 구글 시트에서 확장 프로그램 → Apps Script를 엽니다.
  2. 기본 Code.gs의 내용을 전달받은 UnitCart_Sheets.gs 전체로 교체합니다.
  3. 저장합니다. @OnlyCurrentDoc 표시를 지우지 마세요.
  4. 선택 사항: 왼쪽 프로젝트 설정에서 appsscript.json 매니페스트 파일 표시를 켜고 전달받은 appsscript.json 내용을 사용하면 접근 범위를 명시적으로 고정할 수 있습니다.
  5. 구글 시트를 새로고침합니다. 상단에 한눈단가 메뉴가 나타납니다. 처음 도우미를 실행할 때 Google 권한 화면이 나타날 수 있습니다.

이 스크립트는 현재 스프레드시트와 시트 내부 도우미 화면만 사용합니다. Gmail·Drive 전체 파일·외부 HTTP 호출 권한은 요구하지 않습니다. 웹 앱 배포, API 키 입력, 시간 기반 트리거 생성은 필요하지 않습니다.

사용하는 최소 권한
https://www.googleapis.com/auth/spreadsheets.currentonly
https://www.googleapis.com/auth/script.container.ui

4. 추가된 메뉴 사용법

메뉴하는 일
선택 상품 검색 · 판매가 입력상품이 있는 행을 선택하면 검색 링크와 판매가 입력 화면을 엽니다. 확인한 가격을 저장하면 판매가 시트에 신규 행을 추가합니다.
선택 판매가 확인일을 오늘로가격을 오늘 직접 확인했다고 응답한 경우 날짜만 바꿉니다. 가격·재고·검증상태는 자동으로 바꾸지 않습니다.
사이트 JSON 가져오기사이트에서 내보낸 JSON 전체를 붙여 넣습니다. 기본 동작은 신규 ID 추가이며, 기존 ID는 건너뜁니다.
사이트용 JSON 내보내기현재 시트 기록을 파일로 내려받습니다. 사이트에서 가져오면 동일한 입력 데이터를 사용할 수 있습니다.

같은 기록을 갱신할 때

가져오기 화면의 같은 ID의 기존 입력값도 갱신을 선택하면 해당 ID의 입력값만 교체합니다. 새 ID는 추가됩니다. 수식·서식·다른 행은 유지하며 기록을 자동 삭제하지 않습니다. 두 곳을 동시에 수정했다면 어느 쪽 기록을 적용할지 확인한 뒤 갱신하세요.

사이트의 분류 값은 스크립트 메타데이터에 보관했다가 다시 내보냅니다. 시트에서 새로 만든 상품의 기본 분류는 “기타”입니다.

사진으로 등록한 값 가져오기

  1. 웹사이트에서 사진으로 등록을 선택해 가격표 사진을 고릅니다. 사진의 글자는 기기 안에서 읽습니다.
  2. 인식된 상품명·총 결제금액·총수량·비교단위를 직접 확인하고 수정한 뒤 저장합니다. 정상가·할인가·단가가 함께 적힌 사진은 선택한 금액을 특히 확인하세요.
  3. 웹사이트의 데이터·시트 → 전체 JSON에서 기록을 내보냅니다.
  4. Google Sheets의 한눈단가 → 사이트 JSON 가져오기에 JSON 전체를 붙여 넣습니다. 사진에서 인식한 뒤 확인·저장한 상품 값이 그대로 옮겨집니다.

원본 사진은 시트에 저장되지 않습니다. 이 흐름은 상품 값을 옮기는 기능이며, 쿠팡·네이버의 온라인 가격을 자동으로 가져오지 않습니다. 온라인 판매가와 배송·공식판매처 조건은 직접 확인해 입력합니다.

5. 입력 범위와 문제 해결

  • 상품 100개: 8~107행. 판매가 400개: 8~407행. 이 범위를 넘으면 가져오기를 중단합니다. 범위를 늘릴 때는 시트 수식과 스크립트 용량을 함께 조정해야 합니다.
  • 7행의 제목을 유지하세요. 도우미는 열 제목으로 입력 칸을 찾습니다. 상품의 기준단가·검색 링크·입력상태 및 판매가의 계산 열을 덮어쓰지 않습니다.
  • 같은 ID를 중복으로 넣지 마세요. 중복 ID는 오류로 알려 줍니다.
  • 숫자 칸에는 숫자만: “무료”, “1만 원”, “미확인” 대신 숫자 또는 빈칸을 사용합니다. 배송비의 빈칸은 0원으로 취급하지 않습니다.
  • 가져오기 도중 권한·네트워크 오류가 발생했다면: 일부 행이 저장됐을 수 있으니 먼저 입력 결과를 확인하세요. 기본 “신규 ID만 추가”로 다시 시도하면 이미 들어간 ID는 건너뜁니다.
  • 확인일은 임의 갱신하지 않습니다. 가져오기·내보내기로 이전 가격이 오늘 가격으로 바뀌지 않습니다.
  • 스크립트는 선택 기능: 권한을 연결하지 않아도 기본 시트의 수식 비교와 링크는 사용할 수 있습니다.
